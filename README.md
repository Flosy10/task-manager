# Task Manager
## Описание проекта
Программа создана для составления несложных списков задач с возможностью отметки статуса их выполнения.
## Возможности
- Добавление задачи
- Удаление задачи
- Просмотр задач
- Отметка задачи как выполненной
- Автосохранение данных
## Установка и запуск

Для работы программы необходим установленный Python 3.

1. Скачайте проект на свой компьютер.
2. Откройте папку проекта в PyCharm или терминале.
3. Запустите программу командой:

```bash
python main.py
```

После запуска появится меню для управления задачами.
